# إدارة الحزم في Fedora (dnf)

## الكود
```bash
# تحديث قائمة المستودعات (أول أمر تعمله دايمًا)
sudo dnf update

# ترقية كل الحزم المثبتة لآخر إصدار متاح
sudo dnf upgrade

# تثبيت برنامج
sudo dnf install name

# عرض معلومات عن حزمة معينة قبل التثبيت
dnf info google-chrome-stable
```

## ملاحظات
- `dnf update` بتحدث قائمة الحزم المتاحة من المستودعات، مش بالضرورة بتثبت حاجة.
- `dnf upgrade` هي اللي فعليًا بترقي البرامج المثبتة عندك لآخر نسخة.
- `dnf info` مفيدة تتأكد من اسم الحزمة الصحيح ووصفها قبل التثبيت.
