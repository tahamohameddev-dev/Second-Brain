# عمليات الملفات الأساسية (touch / rm / cp / mv / mkdir)

## الكود
```bash
# عمل ملف جديد فاضي
touch file.txt

# عمل فولدر جديد
sudo mkdir directory_name

# مسح ملف
rm file.txt

# مسح فولدر بكل اللي جواه إجباريًا (خطر - لا رجعة فيه)
rm -rf directory_name

# نسخ ملف لمكان تاني
cp file ./name_file/name_copy

# مسح كل اللي جوه فولدر معين (بدون مسح الفولدر نفسه)
rm name_file/*

# نقل ملف لفولدر تاني
mv name_file name_directory/name_file

# إعادة تسمية ملف (mv بتستخدم للنقل والتسمية مع بعض)
mv name_file1 name_file2

# نسخ ملف من فولدر لفولدر تاني بنفس الاسم
cp file/a.out file_2/a.out

# نسخ ملف وتغيير اسمه في نفس الوقت
cp ./file/a.out ./file/b.out
```

## ملاحظات
- `mv` بتستخدم لحاجتين: نقل الملف لمكان تاني، أو إعادة تسميته لو المصدر والوجهة في نفس الفولدر.
- `rm -rf` من أخطر الأوامر في Linux — بتمسح بشكل نهائي بدون تأكيد وبدون سلة مهملات، لازم تتأكد من المسار قبل ما تنفذها.
- `cp` بتحافظ على الملف الأصلي، أما `mv` فبتشيله من مكانه الأصلي.

## أخطاء شائعة
- تنفيذ `rm -rf` من غير التأكد من الفولدر اللي انت واقف فيه (`pwd`) ممكن يمسح حاجة غلط.
