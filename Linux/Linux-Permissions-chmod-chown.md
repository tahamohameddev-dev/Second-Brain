# صلاحيات الملفات (chmod / chown)

## الكود
```bash
# تغيير مالك الملف والجروب بتاعه
sudo chown root:taha file.txt

# رجوع الملكية بالكامل لـ root
sudo chown root:root file.txt

# تغيير ملكية فولدر بكل اللي جواه (Recursive)
sudo chown -R taha:taha ./file

# صلاحيات كاملة للجميع (خطر - استخدمها بحذر)
chmod 777 file.txt

# صلاحيات شائعة على السيرفرات
chmod 755 file.txt
```

## ملاحظات
### جدول الصلاحيات
| الرمز | المعنى | القيمة الرقمية |
|---|---|---|
| read (r) | قراءة | 4 |
| write (w) | كتابة | 2 |
| execute (x) | تنفيذ | 1 |

الترتيب في الرقم بيبقى: **user (المالك) → group (الجروب) → others (الباقي)**

مثال: `chmod 755 file.txt` معناها:
- المالك (7 = 4+2+1): قراءة + كتابة + تنفيذ
- الجروب (5 = 4+1): قراءة + تنفيذ
- الباقي (5 = 4+1): قراءة + تنفيذ

## أخطاء شائعة
- `chmod 777` بتدي صلاحيات كاملة للجميع، خطر أمني لو استخدمتها على ملفات مهمة أو سيرفر حقيقي.
